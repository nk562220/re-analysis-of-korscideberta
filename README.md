# 청소년 논문 분류 재분석 — 신뢰할 수 있는 정확도 측정

이전 연구(2025)의 정확도 0.0812는 **학습되지 않은 무작위 분류 헤드의 출력**이었고,
정답 레이블도 자기 자신이 만든 클러스터 번호였다(순환 평가).
이 폴더는 같은 데이터로 **정직하게 측정 가능한 정확도**를 다시 구한다.

## 무엇을 바꿨는가

| 항목 | 이전 | 지금 |
|---|---|---|
| 정답 레이블 | K-Means 클러스터 번호(자가 생성) | 과학전람회 공식 `field` 5분야(외부 정답) |
| 분류 헤드 | 무작위 초기화, 학습 안 함 | 실제 파인튜닝 + 조기종료 |
| 평가 방식 | 단일 실행, 정확도만 | 5-fold OOF × 3시드, macro-F1·CI·혼동행렬 |
| 중복 처리 | 지도논문 병합률 300/876 | 773/876 (연도·분야 버킷 + rapidfuzz) |

| 비교군 | 없음 | TF-IDF, KLUE-RoBERTa, KorSciDeBERTa |

## 정확도를 '정확하게' 만드는 다섯 가지 장치

1. **Out-of-fold 평가** — 1,431편 전체가 각각 정확히 한 번, 자신을 학습하지 않은 모델에게
   평가된다. 15% 홀드아웃(215편)보다 표본이 6.6배 커서 수치가 훨씬 덜 흔들린다.
2. **그룹 분할** — 지도논문 잔여분·크롤링 중복처럼 본문이 거의 같은 문서는 같은 fold에 묶는다.
   이걸 안 하면 정확도가 몇 %p 부풀려진다.
3. **3시드 반복** — 표에 `±표준편차`가 찍힌다. 이 폭보다 작은 모델 간 차이는 주장하지 않는다.
4. **그룹 부트스트랩 95% CI + 짝지은 부트스트랩** — "A가 B보다 좋다"를 수치로 뒷받침한다.
5. **macro-F1 주 지표** — 산업및에너지(156편)와 생물(358편)의 불균형 때문에 accuracy 단독은
   소수 클래스를 무시하는 모델을 과대평가한다.

## 확정된 수치 (시드 42, out-of-fold 1,431편)

| 모델 | Accuracy | macro-F1 | Top-2 | 95% CI |
|---|---|---|---|---|
| 최빈 클래스 찍기 | 0.2502 | 0.0800 | — | — |
| TF-IDF + LogReg | 0.6054 | 0.5896 | — | — |
| **KLUE-RoBERTa** | **0.6730** | **0.6625** | 0.8679 | [0.649, 0.697] |
| KorSciDeBERTa | 0.6233 | 0.6104 | 0.8337 | [0.598, 0.650] |
| 세 모델 앙상블 | 0.6841 | 0.6732 | — | — |

**핵심 결과: 과학기술 특화 모델(KorSciDeBERTa)이 범용 모델(KLUE-RoBERTa)보다 5.2%p 낮다.**
짝지은 부트스트랩에서 macro-F1 차이 +0.0521, 95% CI [+0.028, +0.076], p<0.001 로
우연이 아니다. 선행연구가 보고한 "KorSciDeBERTa가 최고 성능"은 전문 학술논문 초록에서의
결과이며, 청소년 논문 문체에는 그 이점이 전이되지 않았다.

단, 이 비교는 두 모델에 **같은 하이퍼파라미터(lr 2e-5)** 를 적용한 결과다.
DeBERTa 계열은 학습률에 민감해서, 결론을 확정하기 전에 lr 1e-5 / 3e-5 를 확인해야 한다.

## 레이블 자체의 한계 (논문 고찰에 쓸 것)

`results/report.md`의 오분류 사례를 보면 모델이 "틀린" 것 중 상당수가 사람이 봐도 애매하다.

- 「고수 추출물을 활용한 항균 마스크」→ 정답 화학, 예측 생물
- 「커피박을 이용한 토양 미세플라스틱 제거」→ 정답 생물, 예측 지구및환경

즉 **정확도 100%는 도달 가능한 목표가 아니다.** 상한선은 과학전람회 심사 분야 배정의
일관성이 결정한다. 그래서 report에 Top-2 정확도를 함께 출력한다. 여력이 있으면
논문 100편을 두 사람이 독립적으로 분야 배정해 일치율(Cohen's kappa)을 재고,
그 값을 모델 성능의 상한 기준으로 제시하면 평가의 설득력이 크게 올라간다.
